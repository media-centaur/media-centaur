Living with it

Still curious? Just run it.

One line installs the latest release, verifies its checksum, and sets up a user service. Linux x86_64 is fully supported; macOS Apple Silicon is experimental. The installer is idempotent — re-run it any time to repair or roll forward.

$ curl -fsSL https://raw.githubusercontent.com/media-centaur/media-centaur/main/installer/install.sh | sh
