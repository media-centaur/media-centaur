The word that matters

Optional by design.

The library, the metadata, the review queue, the playback — none of it depends on downloading a single byte. Acquisition is plumbing you switch on only if you already run indexers and want them surfaced in one place.

Optional by design

Media Centaur is a complete library manager without ever downloading anything. Acquisition is a bolt-on for people who want it — nothing in the rest of the app assumes it's there.

Search via Prowlarr

Point Media Centaur at your Prowlarr instance and you get a search surface for the indexers you've already configured. Prowlarr is the single integration point; your indexers stay yours.

The grab lifecycle

Every grab moves through honest states — Searching → Grabbed → Pending — with Abandoned and Cancelled surfaced plainly rather than hidden. You always know exactly where a request stands.

Pairs with release tracking

A newly-announced season the tracker spots can be found and grabbed in the same flow — release tracking watches, acquisition acts, and the library absorbs the result.

The grab lifecycle.

Better together

Pairs with release tracking.

Release tracking monitors TMDB for new seasons of the shows you already own. When one is announced, acquisition gives you a place to find and grab it — then the file flows back into the same library grid, identified and arted like everything else.

You bring your own Prowlarr and indexers; Media Centaur doesn't ship or endorse any. It's neutral plumbing for content you have the right to — no piracy cheerleading, just a tidy search-and-queue surface.

Try it. Acquisition stays off until you want it.

Downloads the latest release, verifies its checksum, installs atomically, and sets up a service unit. You can run the whole library manager without ever configuring an indexer.

$ curl -fsSL https://raw.githubusercontent.com/media-centaur/media-centaur/main/installer/install.sh | sh
