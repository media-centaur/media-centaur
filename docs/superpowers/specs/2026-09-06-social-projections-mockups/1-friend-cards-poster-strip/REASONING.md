# 1 · Friend cards with a poster strip

**Style.** One glass card per friend, the You card first with a primary-tinted border. Header = avatar, name, key; the right side is the presence line: the latest thing they finished plus relative time. Body = uppercase section label, a six-slot poster strip (five posters + "all N"), then Tracking and Recommended as single text rows. Footer = added date + Remove friend.

**Decisions.** Watched is the visual headline because it is the freshest signal and the one that says "what is Bob into right now". Tracking and Recommended are text rows because they are small sets and a name is enough to recognise them; a poster for a tracked title would give tracking the same visual weight as watching. Recommended repeats the feed's pennant sentiment so the card is the full picture of a friend without leaving the tab. Friends sort by latest activity; a friend with nothing shared collapses to header + footer.

**Requirements.** Watched/tracking as a property of the friend: yes, all three kinds live on the card. Inline first, per-friend page later: the "all N" tile is the seam for the page. You card = the audit view for own sharing, same shape as a friend.

**Trade-offs.** Gains: richest single glance per friend, posters make the shelf scannable. Costs: tallest layout, with ten friends this is a long scroll; the 6-column strip fixes the visible window at five titles regardless of width.
