# Feed 1 · Title rows, one per recommendation

**Style.** Today's row, kept: poster thumb, title, quiet type/year, then the lead, then markers (In library, Downloading, On watchlist), the friend's note where the overview would be, sentiment as an icon-only pennant on the mast. One change: the lead drops the verb. On a tab called Recommendations "Bob recommended" says the same thing twice; "Bob · 2d ago" is enough and the pennant carries how much.

**Decisions.** One row per recommendation, so a title two friends recommended appears twice (Movie B, by Bob and by Cleo), each row's mast showing every friend's sentiment as it does today. Newest first. No grouping, no scope switch.

**Trade-offs.** Gains: zero new component work, the row is shared with the watchlist, the note stays the row's secondary line. Costs: the duplicate rows for a popular title, and a note is clamped to two lines under the title rather than being the thing you read first.
