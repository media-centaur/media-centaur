# T3 · Dark sheet, 1500 — reasoning

**Knobs** surface `sheet` (Q6: ground dark, units ink, flush, hairlines) · width `narrow` · poster 100 · logo none.

## Style

Round 10's page without round 5's picture: Discovery's ground darkened to
the ink, the columns flush with a hairline between rows, the poster row in
them. Narrowed to 1500.

## Decisions

* **Keep Q6's ground.** If the owner liked the dark page and only the still
  is unwanted, this is that page with the still gone.
* **Flush, not contained.** The sheet is one surface per column with the
  column's corners; the hairline runs the row now that there is no picture
  to stop at.

## Requirements

* *No backdrop* — none.
* *Like the app* — less so than T1: the dark ground is Discovery's own.
* *Narrower columns* — 1500.

## Trade-offs

Gains: the darkest, quietest page; the posters carry all the colour.
Costs: without the stills the dark ground has less to justify it — the
page is a dark list where T1 is the app's list; the ink rows on a
near-ink ground rely on the hairlines alone. In the app: round 10's Q6
rules with the band's still removed.
