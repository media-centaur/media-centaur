# Test-sweep keeps

Every test `scripts/test-sweep` flags carries a row here, or `mix precommit`
fails (`scripts/test-sweep check`). A row is the owner's verdict that the
test earns its place by the one criterion every test is held to: a plausible
accidental breakage exists, and the failure would name the behaviour. The
`automated-testing` skill carries the criterion and the vocabulary; the
script's header lists the signatures.

Rows are keyed by file and test name as written in the source, so a renamed
or re-aimed test is a new candidate and its old row is reported stale.
`failing diff` is the change that would turn the test red. A row comes out
when its test is gone or no longer flagged, never to quiet the check.
